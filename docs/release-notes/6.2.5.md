## Improvements

- Open files in your preferred editor or choose another from **Open With…**. Anser preserves line and column information where supported and offers recovery options when an editor fails to launch.
- Use **Open Project in Editor** to open the Git root or the current folder.
- Library search and actions sit below the native tab bar.
- The folder icon aligns with the prompt, and the Stop button shows progress while a command responds to an interrupt.
- Welcome tips sit above the input bar and provide quick access to the command palette and tour.
