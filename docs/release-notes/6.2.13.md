## Fixes

- **A running script stays on one row.** While a command of several lines runs, the input shows its first line and how many more (`export HF_HOME=…  +3 lines`) instead of spilling over the output and the status row.
- **Prompt themes stay hidden behind the input.** Themes that insist on drawing last, like powerlevel10k (especially after `source ~/.zshrc`), no longer show their prompt and a hollow cursor under Anser's input line. Tabs opened before updating keep the old behavior until you open a new tab.
