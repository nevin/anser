# Anser brand guide

Everything here is generated by `swift scripts/make-brand.swift` (run from the repo root). Don't edit the
exported files by hand — change the script or the source shapes and regenerate.

## The idea

A terminal prompt `>` and a quill writing the cursor `_`. Anser is Latin for *goose*, and quill pens were cut
from goose feathers, so the mark says "a terminal you write in" and carries the name.

## Logo

| Asset | Use |
|---|---|
| `icon/anser-icon.svg`, `icon/anser-icon-*.png` | App icon, store listings, anywhere the icon appears on its own |
| `lockup/anser-lockup-on-dark.*` | Icon + wordmark on dark backgrounds |
| `lockup/anser-lockup-on-light.*` | Icon + wordmark on light backgrounds |
| `mark/anser-mark-on-dark.*` | The glyph without its tile, for dark surfaces |
| `mark/anser-mark-on-light.*` | The glyph without its tile, for light surfaces |
| `mark/anser-mark-mono.svg` | One-colour uses: engraving, stamps, single-ink print |
| `wordmark/anser-wordmark-*.svg` | The name alone, when the icon is already nearby |

**Sizes.** The icon has three drawings, chosen automatically:
- 128px and up: the full feather with all its barbs.
- 32–64px: the feather silhouette, with the prompt and cursor drawn heavier so they stay sharp.
- 16px: only a bold `>_` prompt, since a feather can't be read at that size.

Don't show the lockup smaller than 24px tall, or the bare mark smaller than 20px.

**Clear space.** Keep empty space around the icon or lockup equal to at least the cursor's length. Never put
text or other marks inside that space.

**Don't:**
- recolour the mark outside the palette below, or put the cream mark on a light background;
- stretch, rotate, outline or add effects (glows, bevels) to it;
- rearrange the parts — the nib always lands on the start of the cursor;
- set the wordmark in another typeface.

## Colour

| Name | Hex | Use |
|---|---|---|
| Navy | `#141635` | Brand colour; text on light backgrounds |
| Navy, light | `#1E2152` | Top of the icon tile's gradient |
| Navy, deep | `#0E1029` | Bottom of the icon tile's gradient |
| Cream | `#FBF0DB` | Prompt and quill; text on dark backgrounds |
| Mint | `#7AE9B1` | The cursor and accents, on dark backgrounds only |
| Mint, deep | `#1E9E66` | The cursor and accents on light backgrounds |
| Paper | `#FBF7EF` | Light backgrounds |

Contrast: cream on navy is 15.5:1 and mint on navy 11.8:1, so both work for any text on dark. Deep mint on white
is 3.4:1, which is enough for graphics and large text but not small body text; use navy for that.

## Type

- **Wordmark and headings:** Charter Bold (Bitstream Charter, free licence; ships with macOS). The serif nods to the
  quill and to writing.
- **Everything else:** the system font (SF Pro on Apple platforms).

## Release files

| File | Where it goes |
|---|---|
| `Resources/AppIcon.icns` | The app bundle (copied in by `scripts/build-app.sh`) |
| `dmg/dmg-background.tiff` | The installer window (used by `scripts/release.sh`, which also sets the disk icon) |
| `social/github-social-preview.png` | GitHub → Settings → Social preview (1280×640) |
| `social/readme-banner-dark.png`, `-light.png` | Top of the README; GitHub picks the one matching the reader's theme |
| `web/favicon.ico`, `favicon.svg`, `favicon-32.png` | Website favicon |
| `web/apple-touch-icon.png` | iOS home-screen icon (180×180, square; iOS rounds it) |
| `web/icon-192.png`, `icon-512.png` | Web app manifest icons |

Website `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<meta property="og:image" content="https://YOUR-SITE/github-social-preview.png">
```

## Sources

- `source/feather.path` — the feather's outline (SVG path data in the original artwork's 1254px coordinates),
  traced from `source/original-artwork.png`. The prompt and cursor are exact geometry in `scripts/make-brand.swift`.
- `source/original-artwork.png` — the approved artwork everything is based on.
