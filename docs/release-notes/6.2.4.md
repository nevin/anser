## Fixes

**Switch branch works in more repos**
- In projects that use husky or another tool that sets git's hooks folder (common in Node projects), Switch Branch (⇧⌘B) opened with an empty list, and the changed-files count and blame were off. They work again. Anser still never runs git hooks for its own checks.
- In a repo whose settings could make git run a program, Switch Branch now says why it's unavailable instead of opening empty.
