## What's new

**The input line flows with the output**
- You type on the line right after your last command, on the terminal's own background, like a shell prompt. No separate input bar to look down to.
- The status row (folder, branch, chips and hints) stays at the bottom where it always was.
- When the screen fills up, or you scroll back, the input line rests just above the status row.
- Prefer the input at the bottom? Turn off **Settings → Editor → Input line follows the output**.

## Fixes

- The old "follow short output" option placed the input about two rows below the output on Retina screens. It now lines up exactly with the terminal's rows.
