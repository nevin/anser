## What's new

**The input line keeps still while a command prints**
- While a command keeps printing (a build, logs, `tail -f`), the input line stays at the bottom instead of drifting down line by line. It follows the output again at the next prompt.
- Quick commands and ones that print nothing don't move it.

**The input line looks like the terminal's next row**
- Its ❯ now sits on the terminal's first column, right under the ❯ of the commands above, and what you type starts in the same column as those commands.
- The ❯ uses the same weight as the others. Its colour still shows whether the last command worked.

## Fixes

- Pressing Enter with nothing typed no longer leaves an empty ❯ row behind.
