## Faster tabs that keep their shells

- **Kept tabs are as fast as plain ones.** With "Keep shells running" on (the default), a tab now reads its shell directly instead of through a helper in between. Heavy output, like a big build log or `cat` of a large file, streams about twice as fast as before, the same as a tab without kept shells.
- **History survives quits, updates and crashes.** Quitting or updating hands each tab's recent output to the session helper, and every few seconds open tabs send it a copy, so even after a crash your shells come back with their output (at most the last few seconds are missing). The shells themselves keep running as before.
- If a session helper from an older Anser is still running after an update, tabs start the old way until it ends, with no difference you'd notice.

## Fixes

- **Clicking under the input focuses it.** At a prompt, the empty space between the input and the status row now counts as part of the input: click there to start typing.
- **The pull-request chip follows the branch.** After switching branches in another tab, your editor or a git app, the chip no longer shows the old branch's pull request; it shows the new branch's, or none.

## Known limits

- Pictures sent with iTerm2's own picture codes (from third-party tools) don't show in kept tabs yet. Anser's `imgcat` and kitty pictures work as before.
