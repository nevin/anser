## What's new

**Anser updates itself**
- From this version on, Anser checks for a new version once a day and offers to install it. Your shells keep running through the update.
- Help → Check for Updates checks right away. Settings → Sessions & Windows turns automatic checks off.
- This is the last version you need to download by hand.

**A cleaner input area**
- Thin dividers set the editor apart from the output and from the hints row below it.
- The folder, git status and other chips stay on their own row, so long commands have room.

**The line after each command**
- Choose a dotted line in Settings → Editor → "After each command". Anser draws it to the edge of the window, so it fits at any width.

**Resizing**
- Output keeps its alignment when you resize the window. Lines a smaller window pushed out of view come back when it grows again.
- A long command that wraps after the window gets narrower no longer confuses where prompts start.

**Lighter on battery**
- The server and port chips are checked less often while nothing changes or Anser is in the background, and not at all when nothing is running. They also cost far less to check.
- The running indicator spins for a few seconds, then settles into a still dot, so long-running servers and agents don't keep redrawing.

**Fixes**
- Time the Mac spent asleep is no longer logged as Anser freezing. A real freeze now logs what Anser was doing, to make it easier to fix.
