A terminal you write in_

Anser is a fast, native macOS terminal built on Ghostty's GPU engine, with a real command editor, history that remembers, and git at a glance. No account, no cloud, no telemetry.

Helpful like a modern editor, fast like Ghostty

Everything you type goes through a real editor, and everything you run is remembered, so the terminal gets out of your way.

❯_

A real editor for commands

Select with the mouse, use multiple cursors, and get completions for git, npm, docker, kubectl and 700+ more tools, plus gray suggestions from your history.

⟲

History that remembers more

Every command with its folder, branch, exit code and time, plus searchable output. Typos get a one-click fix, and a History window shows what works and what doesn't.

⑂

Git at a glance

Branch, changed files, pull request checks and merge conflicts in the status row. Switch branches with ⇧⌘B, see changes with ⇧⌘G.

∞

Shells that survive

Quit, restart or update Anser and your running commands keep going. Your tabs reconnect to them with their recent output.

✎

Command Notebook

Save commands and step-by-step workflows with {{values}} to fill in. Sync them through iCloud or a git repo.

!

Safe by default

Profiles color production tabs and ask before risky commands. Secrets stay out of history, and repo files can't make Anser run code.

Nothing leaves your Mac

Anser is a terminal, not a service. There's nothing to sign up for.

No account

Download it and start typing. Your history and Ghostty theme come along on first launch.

No telemetry

Usage stats, if you turn them on, stay on your Mac for you to read.

AI only if you want it

Off by default. Bring your own Claude key, your Copilot plan, or a local model through Ollama.

Uninstalling Anser
  1. Quit Anser with ⌥ Quit: hold Option in the Anser menu. A plain Quit keeps your shells running in the background; ⌥ Quit ends them too.
  2. Drag Anser from Applications to the Trash.

That removes the app. Your settings and history stay on your Mac in case you come back. To remove those too, run this in any terminal:

# Shells still running in the background
pkill -x anser-session
# Settings, notebook, history, saved windows, caches and logs
rm -rf ~/.config/anser \
  ~/Library/"Application Support"/Anser \
  ~/Library/Caches/Anser ~/Library/Caches/app.anser.terminal \
  ~/Library/HTTPStorages/app.anser.terminal \
  ~/Library/Logs/Anser \
  ~/Library/"Saved Application State"/app.anser.terminal.savedState
# Preferences: window sizes, panels, tips
defaults delete app.anser.terminal 2>/dev/null
# Your AI key and saved secrets in the Keychain
while security delete-generic-password -s Anser >/dev/null 2>&1; do :; done
while security delete-generic-password -s app.anser.terminal.secret >/dev/null 2>&1; do :; done

~/Library/Application Support/AnserCommand history and saved output, saved windows and tabs, background shells
Caches, HTTPStorages, LogsCaches and logs, safe to delete any time
KeychainYour AI API key and any secrets you saved

If you turned on sync, Anser also wrote to the folder you picked, for example iCloud Drive/Anser. Anser never edits your .zshrc, .bashrc or shell history, so there's nothing to undo there.
