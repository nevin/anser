## What's new

**A calmer screen**
- **No more separator rows between commands.** A faint line divides them, and each command's row ends with the time it ran (and the host, over SSH). The same output now fits in about a quarter fewer rows. Want the old "you@mac · time" rows back? **Settings → Appearance → After each command**.
- **A failed command is shown once,** on the command itself: its red bar and ✗ exit code. The status row no longer repeats the exit code, and the input's ❯ stays grey instead of turning red.
- **"Edit & retry" steps aside** once you start typing something else, and comes back if you clear the input.
- **Shortcut hints retire as you learn them.** Each hint under the input (⇥ complete, ↑ history, ⌘R search…) goes away after you've used it three times. **Settings → Editor → Keyboard tips → Always** keeps them all.

**Long commands and big pastes**
- The input grows to show all of a long command or paste, up to the window's height, then scrolls with a scroll bar. There's no length limit.

## Fixes

- The terminal no longer flickers while the input is several lines tall.

## Good to know

- If your settings file still has the old defaults for separator rows and keyboard tips, Anser switches them once to the new ones. You can change either back in Settings.
