## Fixes

- **The branch stays current.** Switch branches in another tab, your editor or a git app, and Anser's branch chip, the sidebar's Git section and the tab's tooltip follow straight away, without waiting for your next command.
- **One click focuses the pane.** Clicking a pane in a window that isn't in front (or with Anser in the background), including the empty space under the input, now focuses that pane instead of only bringing the window forward. That click only focuses; it doesn't reach the program running in the terminal.
