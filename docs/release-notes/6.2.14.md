## Fixes

- **No stray cursor box under the input.** At a prompt, Anser now hides the terminal's own cursor itself, so a prompt theme, a program or a setting can't bring back the hollow box under where you type. A program you run (vim, a password prompt) gets its cursor as usual.
- **Times and results stay off your text.** The time and `✗ exit 1` marks on a command's row step aside when something else is on that row, like the right-hand part of a prompt theme.

## Faster

- Big output shows up to a quarter faster: the helper that keeps your shells running no longer searches and copies every piece of output, and passes it on in bigger pieces.
- Typing does less work per key: the window only rearranges itself when the input's height or hint changes.
